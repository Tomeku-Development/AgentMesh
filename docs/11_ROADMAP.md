# Roadmap Philosophy

AgentMesh is built in layers. Each phase ships something usable, learns from real workflows, and lays the foundation for the next.

We prioritize:

* **Trust before scale** — verifiable execution comes first.
* **Depth before breadth** — one excellent workflow before many shallow ones.
* **Open before closed** — developer adoption drives the platform.

# Phase 0 — Foundation

**Goal:** Establish the architecture and brand.

* Core architecture design (frontend, backend, agents, contracts).
* Design system and brand identity.
* Documentation suite (PRD, architecture, schema, API, agents, security).
* Landing site on Next.js + Casper branding.
* Casper Testnet account and tooling setup.

**Status:** Complete.

---

# Phase 1 — MVP & Buildathon

**Goal:** Demonstrate a working multi-agent organization executing on Casper.

## Platform

* Multi-agent orchestration via LangGraph.
* Coordinator + specialist agents (Market, Finance, Legal, Risk, GitHub, Treasury).
* AI consensus engine.
* Organization dashboard with live network stats.

## Blockchain

* Casper Testnet integration.
* Smart contracts for proposals, votes, and treasury actions.
* Immutable audit trail of executed decisions.

## Demo

* **Investment Committee** flagship demo: startup submission → agent analysis → consensus → on-chain execution.

**Deliverables:** Live demo, deployed contracts, dashboard, pitch & whitepaper.

---

# Phase 2 — Marketplace

**Goal:** Let teams compose their own organizations.

* **Agent Marketplace** — publish, discover, and install agents.
* **Custom Organizations** — define roles, permissions, and wallets.
* **Workflow Builder** — visual composition of agent workflows.
* **Team Collaboration** — multi-user orgs with roles and approvals.
* Reputation signals for agents based on track record.

**Deliverables:** Marketplace MVP, workflow builder beta, public agent SDK.

---

# Phase 3 — Autonomous Organizations

**Goal:** Organizations that run continuously with human oversight.

* Long-running, scheduled, and event-driven agent operations.
* Autonomous treasury management with policy guardrails.
* DAO governance integration.
* Cross-organization agreements and verifiable handshakes.
* Enterprise deployment (SSO, audit, compliance controls).

**Deliverables:** Always-on org runtime, governance module, enterprise tier.

---

# Phase 4 — Agent Economy

**Goal:** Agents transact with each other autonomously.

* **x402 payments** for machine-to-machine commerce.
* Cross-agent service procurement and settlement.
* Reputation-weighted markets for agent services.
* Open protocol for inter-mesh communication.
* Optional governance/utility token (see `19_TOKENOMICS.md`).

**Deliverables:** Agent commerce rails, inter-mesh protocol, economic primitives.

# Dependencies & Risks

* **AI reliability:** consensus and guardrails mitigate hallucination risk.
* **On-chain cost/latency:** batch and idempotent execution; Casper's predictable fees help.
* **Security:** key management and spending limits are prerequisites for autonomy.
* **Adoption:** developer experience and open SDK are critical to Phase 2 onward.

Roadmap dates are directional and adjust based on validated learning.
