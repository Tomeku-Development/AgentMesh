## How to Read These Docs

Start with the **Overview**, then branch by interest:

* **Building it?** → Architecture → Database → API → Agents → Smart Contracts → Deployment
* **Designing it?** → UI/UX → Design System → Branding
* **Pitching it?** → Whitepaper → Pitch Deck → Demo Script → Competitor Analysis → Go-To-Market
* **Strategy & ecosystem?** → Roadmap → Casper Alignment → Tokenomics
